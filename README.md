# spinning-donut

A spinning ASCII donut rendered in the terminal, written in Java.

![Spinning ASCII donut](assets/donut.gif)

## Running

From the repository root:

```sh
javac -d out src/Donut.java
java -cp out Donut
```

Press `Ctrl+C` to stop.
